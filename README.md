# CASA0005 Homework 4: Global gender inequality

This repo maps the change in the Gender Inequality Index (GII) between 2010 and 2019, using R Markdown.

## Data

The data folders are not stored in this repo because of GitHub's file size limit. To re-run `homework4.Rmd`, download these into a folder called `week4_data`:

- **Gender inequality data:** UNDP Human Development Reports data centre, "All composite indices and components time series (1990-2023)" (https://hdr.undp.org/data-center/documentation-and-downloads)
- **World spatial data:** world countries boundaries (.geojson) from ArcGIS Hub (https://hub.arcgis.com/datasets/2b93b06dc0dc4e809d3c8db5cb96ba69_0/explore?location=-2.688200%2C0.000000%2C1.41)

## Files

- `week4_homework4.Rmd`: the analysis
- `week4_homework4.html`: the knitted output
